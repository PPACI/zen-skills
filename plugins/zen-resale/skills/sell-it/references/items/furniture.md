# Furniture

## Before writing

Ask the user, in one question, what the photos cannot show:

- Are storage boxes, inserts, doors, or shelves included, or is the frame sold alone?
- Any scratches, chips, or loose parts? Ask for close-ups of the top and edges.
- Sold assembled, or disassembled? Can the buyer disassemble it on site?

## Listing

- Marketplace: Leboncoin with hand delivery; furniture does not fit Vinted's parcel sizes.
- Fields: brand and model line, configuration (for cube shelving, columns x rows and number of cubes), colour as the brand names it, approximate dimensions (width x height x depth), condition, what is included, assembled or not.
- Title: brand, model, configuration, colour ("Étagère <marque> <modèle> 12 cases (3x4) <couleur>"). Name the configuration: buyers search by size.
- Description: pickup only, the town, a vehicle warning for large pieces, and whether it can be disassembled together on site.
- Sell identical small units as one lot with a unit price in the description ("<prix> les deux, ou <prix> l'unité"): one listing and one pickup for the seller.

## Pricing

- Start from the current new price; used flat-pack furniture in good condition sells at about half to two thirds of it.
- Check Leboncoin's recommended range on the price field, and similar listings nearby: the listing page shows "Ces annonces peuvent vous intéresser" with local prices.
