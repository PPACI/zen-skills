# AI writing patterns

Patterns catalogued by Wikipedia's "Signs of AI writing". Replace or delete each one found.

## Words

| Flag | Replace with |
| --- | --- |
| additionally | also, and, or restructure |
| align with | match, fit, follow |
| crucial, pivotal, key (adjective) | delete; say what it does or changed |
| delve | explore, examine, look at |
| enduring | lasting, or be specific |
| enhance | improve, sharpen, strengthen |
| fostering | building, encouraging |
| garner | earn, attract, get |
| highlight, underscore, showcase (verbs) | show, point to, confirm |
| interplay | interaction, relationship |
| intricate | describe what is complex |
| landscape, tapestry (abstract) | name the actual thing |
| testament | evidence, sign |
| valuable, vibrant | delete if filler |

## Structure

- **Superficial -ing clauses**: "shipped, improving performance". State what happened, with numbers.
- **Challenges/future ending**: "Despite challenges… bright future". Delete both sentences.
- **Rule of three**: check whether two items are sharper than three.
- **Not only… but also**: write a direct statement.
- **Is/are avoidance**: "stands as", "serves as". Use "is", or say what it does.
- **False ranges and vague quantities**: "between 50 and 100", "numerous". Give the number, or "several" / "many".
- **Title Case Headings**: use sentence case.
- **Em dashes for emphasis**: at most one per page.

## Content

- **Significance puffery**: "marks a pivotal moment", "plays a vital role", "is a testament to", "setting the stage". Delete; state the fact.
- **Promotional language**: "nestled in the heart of", "world-class", "cutting-edge", "breathtaking". Replace with verifiable claims.
- **Vague attributions**: "experts say", "studies show". Name the source or drop the claim.
- **Section summaries**: "In summary", "Overall" plus a restatement. Delete.
